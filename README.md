# Split Layer Drills

Typing drills for a 36-key split keyboard with BASE, FN (symbols/numbers) and NAV layers.

**Live:** https://jeffssc.github.io/split-layer-drills/

## Drills

- **Words, Brackets, Operators, Numbers, Code** – type the text; the on-screen keyboard highlights the next key and the layer to hold.
- **Navigation** – hold Space for 200 ms (NAV layer) and hit the arrow / Home / End / selection combos.

Tracks WPM, accuracy, personal bests and per-key miss rates (stored in `localStorage`).

## Run locally

It's a single static `index.html` — open it in a browser, or `npx serve .`.
